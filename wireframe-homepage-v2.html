Change log & design decisions

§1 · HERO
Keep as-is. No wordmark repeat — brand is already in the header. Rotating lyric stays. Centered serif quote works well.
§2 · SUTRAS (moved from §8)
Moved up. Colored sutra tiles are the first visual "color hit" after the hero. Solves the "too text-heavy above fold" problem without adding images. 4-col on desktop/tablet → 2-col on mobile.
§3 · NOW PLAYING (merged)
Latest Drops + Have a Bite merged. Two listening sections in a row was confusing. Now: image cards left, track list right (desktop) → stacked on mobile. Single unified mini-player design for both homepage and /listen.
§4 · FEELING LUCKY (revised)
Horizontal strip (matches existing layout). Reload button added. No play overlay — covers link to song page. Bertrand CTA is a plain text link, no avatar/duck icon.
§5 · SONGBOOKS (expanded)
1 card → 3 cards. One topic/sutra · one genre/best-of · one language — representing the three types of songbook. Metadata shown as plain text line, not tag pills. CTA is the only button element.
Removed · Three Doors + Duplicate Sutras
Three Doors removed: LEARN/LISTEN/WATCH live in the nav header. Start Here removed: sutras already appear in §2. No content is lost.
Mini player · /listen alignment
Proposed unified mini-player: thumb · title/sutra/bar · prev/play/next controls. Same component on homepage (inline, loads on tap) and /listen (persistent bar). No persistent player for single-track play.
Performance notes
Sutra tiles: no images, CSS only — zero load cost. Drop cards: lazy-load cover images. Lucky strip: random 11 picks server-side, no JS carousel. Songbook SC embed: defer until visible (intersection observer, as existing).
/learn · /listen · /watch suggestions
/learn: "Feel it in a song" mood picker is good — consider moving above "Ways to explore". /listen: Align track list style + mini player with homepage. /watch: Consider adding 3 featured video cards above the full video wall to ease cold landing.
